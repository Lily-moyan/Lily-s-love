# 世界观与主线

## 一、这套系统是怎么运转的

### 苦情剧的定义（全书第一句设定，也是唯一的"理论"）

> 苦情剧：只要女主角宽容善良地原谅，无怨无悔地付出，一退再退地忍让，忍到欺负她的坏人都老了、作不动了，就会得到圆满大结局的故事。

**王昭帝的原话：**
> 我听懂了。翻译一下就是：你被他们耗一辈子，耗到他们动不了了，这事就算完了。

### 三层结构

| 层 | 是什么 | 出场方式 |
|---|---|---|
| **剧本层** | 一个个苦情剧世界。里面有女主、有施害者、有固定剧情 | 她每次穿进去 |
| **系统层** | 派发节点清单、结算、判定过没过。**正文里它只是"一个声音"**，本质是管劳资的领导 | 【】方括号提示 |
| **幕布之后** | **观众。**他们不进来、不说话、不给她反馈 | 全书几乎不出现，只在每个世界结束后透一点 |

### 观众（真正的反派）

**规则一：不实时互动。**
她演出的时候，幕布后面永远没有声音。骂不到人，翻不了脸，没有弹幕，没有评委席。

**规则二：只出结果后调整方案。**
一个世界演完，观众看结果——如果结果不是他们要的，他们不罚她，他们**改规则**。
下一轮她进新世界，节点清单就变了，堵上一个她上次钻过的空子。

**规则三：他们永远不生气。**
这是最可怕的地方。他们不是在报复她，他们是在**优化**。
她赢一次，方案迭代一次。她再赢一次，方案再迭代一次。

**所以她的目标不是打败谁，是让这套"评估—调整"走到它自己的尽头：每改一次都更糟，最后无解。**

### 系统的嘴（写作素材，直接抄）

```
【欢迎进入剧本世界 007。剧本名：《哑妻》。】
【宿主身份：女主。】
【剧本分配姓名：翠儿。】
```
```
【节点提醒：请在今日之内完成"被婆母罚跪"节点。】
```
```
【亲，您的节点——被继母毒打——已完成。祝您愉快。】
```
```
【检测到节点执行方式异常。经复核，节点名目成立，结算通过。】
【已上报。】
```

> **"已上报"这三个字，是全书最凉的三个字。**它意味着她赢了这一局，但方案已经在改了。

---

### 一条必须遵守的规则：名字是沿用的

**系统分配给她每一个世界的名字，都是那个世界里前任女主用过的名字。**

这不是巧合，是流程：同一个剧本被反复跑过，同一个身份被反复用过，**同一个名字就一直传了下来。**

**所以"名字"在这本书里不是称呼，是遗物。**

- **世界 1**：她从灶台后头的灰里摸出半张卖身契，上面的名字是**小怜**——正是系统刚刚派给她的名字。
- **从世界 2 起**，她进新世界的第一件事变了：**先去找那个名字的痕迹。**
  > "上一个婉君，埋在哪。"

**写作要求**：这条规则**不解释、不点破**。只在世界 1 正面用一次，之后靠她每一次"先找痕迹"的动作，让读者自己拼出来。

## 二、过关规则：节点制

### 规则原文

每个世界开场，系统发一份**节点清单**。节点是剧本里必须发生的关键事件。全部发生，本世界结算通过，她可以离开。

**系统只判定两件事：**
1. 这个节点，发生了没有。
2. 事件涉及的角色，对不对。

**系统不判定：**
- 谁对谁
- 谁受伤
- 后果是什么
- 她的态度、表情、有没有笑

### 她怎么钻

| 剧本节点 | 别人以为的样子 | 王昭帝的执行方式 | 系统判定 |
|---|---|---|---|
| 女主被继母毒打 | 她挨打 | 她走过去，把继母按住打完了 | 【节点·毒打 ✓】 |
| 女主被赶出家门 | 她流落街头 | 她把家里的钱、粮票、房契一起带走，出门 | 【节点·驱逐 ✓】 |
| 女主替弟弟顶罪 | 她认罪 | 她认，同时把弟弟干过的事按日期整理好，寄给对家 | 【节点·顶罪 ✓】 |
| 女主含泪原谅仇人 | 她说"我原谅你" | 她当着全村人的面说"我原谅你"，说完把证据念了一遍 | 【节点·原谅 ✓】 |
| 女主嫁给男主 | 她嫁 | 她嫁，然后在婚礼第二天把男主家分家拆了 | 【节点·成婚 ✓】 |

**这张表就是这本书的全部玩法。**写每个世界的时候，先看节点，再想"怎么执行才能让结果全崩"。

### 系统会反击

从第 4 个世界开始，观众开始改方案：

- **第一次改**：节点描述变精确——从"被毒打"改成"被继母用手掌击打左脸三次"。
  她的应对：她抓着继母的手，让她打了左脸三次。✓
- **第二次改**：节点加了"结果要求"——"女主需因此受伤"。
  她的应对：她去山上采药，自己摔了一跤，回来跟继母说"您昨天打得真重"。✓
- **第三次改**：节点加了"情绪要求"——"女主流泪"。
  她的应对：切洋葱。✓
- **最后一次改**：节点要求"女主必须发自内心地原谅"。
  **她卡住了。**这是全书的主线转折点——因为"发自内心"没法伪造。
  然后她想通了一件事：**他们的整套机制，靠的是她真的在意。**
  她在意的越少，他们能考核的东西就越少。当她把"在意"这一项清零，规则就再也没有东西可以考核了。

**这就是结局的引信。**

## 三、金手指：前任女主的痕迹

### 能力

**她看得见上一个女人留下的痕迹。**

不是鬼魂，不是记忆。就是物件——一个洗好的碗、墙上一道指甲划痕、一本写到一半的日记、衣柜里一件没带走的旧衣服、灶台上一撮没烧完的纸。

别人看不见这些"是痕迹"。她一眼就认得出。

**为什么是她？**因为她上一世就是这么死的。**她也留下过痕迹。**她认得那种痕迹——因为那些东西，就是她自己那辈子留下的东西的同一种。

### 这条线的三个功能

1. **情报**：痕迹里有上一个女人知道的事。日记里有名字，划痕在窗框内侧（说明她被关过），碗洗得很干净（说明她最后还是想做个好人）。
2. **情绪**：这是全书**唯一不搞笑的部分**。王昭帝看见那道划痕的时候，一次也不吐槽。她只是把它记下来，然后去做她该做的事。
3. **主线**：这些女人是谁？她们去哪了？为什么系统每一个世界都要死一个？

### 主线揭示的三段

**第一段（前 3 个世界）**：她以为痕迹是"上一轮失败的宿主"留下的。她拿它当情报用。

**第二段（第 4–6 个世界）**：她发现痕迹太多了。一个世界不止一个女人的痕迹——有的在墙上，有的在柜子里，有的在灶台后头。**有些痕迹是很久以前的，有些是刚刚的。**
也就是说：**这个世界被反复演过。而每一个版本里，都有一个女人死在这里。**

**第三段（第 7–8 个世界）**：她走进一个世界，看见了一样东西。
那是她自己的字。那是她自己洗的那个碗。
**这个世界，她来过。**
**她上一世的那出戏，就是这些剧本里的一个。**

而更冷的是：**她留下的痕迹，在她被系统拖走之后，被另一个女人看见过。**那个女人现在在哪，她不知道。

> 这一段是全书的情绪最高点。写法要极度克制：**不要写她哭，不要写她喊。写她伸手把那个碗拿起来，看了看，然后放回原位。**

## 四、主线结构（六卷）

| 卷 | 内容 | 世界 | 字数 |
|---|---|---|---|
| **卷一** | 第一章她死掉。她被拖走。教学关：她摸清规则 | 世界 1 | 约 4 万 |
| **卷二** | 她开始熟练地钻空子，笑点最密 | 世界 2–3 | 约 7 万 |
| **卷三** | 她发现痕迹的规律：一个世界不止死过一个女人 | 世界 4–5 | 约 7 万 |
| **卷四** | 观众开始改方案针对她。她被逼到要"发自内心原谅"的那一步 | 世界 6–7 | 约 8 万 |
| **卷五** | 她撞上自己的过去。她上一世的戏，就是这些剧本之一 | 世界 8 | 约 5 万 |
| **卷六** | 终卷。规则改到自相矛盾，系统自崩。她走出幕布 | 幕布之后 | 约 4 万 |
| | | **合计** | **约 35 万** |

## 五、结局（必须钉死的三个画面）

**画面一 · 规则的死**
系统最后一次改方案，改出了一个自相矛盾的节点：
```
【节点更新：女主须发自内心原谅，且不得认为"原谅"是必要的。】
```
**一件事不能同时要求她"真心原谅"和"不必原谅"。**
系统卡住了。它开始重复输出同一行提示。她站在那里，看着那行字一遍一遍地刷过去。

**画面二 · 幕布**
她掀开幕布，走出去。
**观众席是空的。**
或者更冷一点：**观众席上还有东西——方案。新的方案。而她看懂了：他们永远不会停。**
**只是这一次，她让他们的方案自己撞死了。**

**画面三 · 最后一笔（一个动作，不是一句情绪）**
她走出那个空间。
**外面是什么，全书不写。**
她做的最后一件事——**她把自己的名字写在了某个地方。**
比如，她在门框上刻了三个字：王昭帝。
> **因为上一个女人留下的痕迹，是别人看见的。这一次，她自己留。**

**到这里结束。不许再写一个字。**
