# 《朕不演了》· 定稿与硬约束

> 女频 · 快穿 · 沙雕爽文 · 反苦情剧
> 晋江文学城 / 同类女频付费站 · 长篇 · 35 万字量级 · 8–10 个世界

---

## 一句话故事

她上一世是一个苦情剧女主，忍了一辈子，八十二岁"圆满"地死了；死后被抓去当各个苦情剧世界的女主替补，而那里的规则只考核"剧情节点有没有发生"——于是她开始钻"节点定义"的空子，一路把剧本演成灾难，直到幕后的观众把规则改到自相矛盾。

## 一句话内核

**他们要看她忍，她偏要在里面当皇帝。**

## 书名

**《朕不演了》**（推荐）
备选：
- 《朕不演了[快穿]》
- 《王昭帝拒绝演出》
- 《我在苦情剧里当皇帝》
- 《苦情剧女主她罢工了》
- 《节点已完成，祝您愉快》

## 设定总表

| 项 | 设定 |
|---|---|
| 女主 | **王昭帝**（她给自己取的名） |
| 前世 | 苦情剧女主，原名"招娣"，忍到八十二岁"圆满"死去 |
| 处境 | 死后被系统收走，成为各类苦情剧世界的"女主替补" |
| 为什么是她 | **她死过一次，所以她认得这套剧本怎么杀人** |
| 系统 | 正文里只是"一个声音"。本质是管劳资的领导，公事公办，只发节点清单，从不解释 |
| 观众 | 幕布后面的人。**不实时互动，只在世界结束后看结果，然后改方案** |
| 过关规则 | **节点制：只考核"节点有没有发生"，不考核"怎么发生"、不考核结果** |
| 金手指 | **她看得见前任女主留下的痕迹**——每个世界都死过一个女人 |
| 性格 | 泼辣行动派。能动手绝不吵嘴，先打了再说 |
| 调性 | **一路沙雕爽到底**。吐槽密集，节奏快，一个世界一掀桌 |
| 结局 | 她一路赢、系统一路改，最后规则改到自相矛盾，系统自崩。她走出幕布，观众席是空的 |
| 第一章 | 她八十二岁"圆满"地死掉，然后被系统拖走 |

## 沙雕爽五条铁律（这是全书能不能成的东西）

**铁律一：她自己的惨，永远只用一句轻描淡写的吐槽带过，一次都不许抒情。**
> 我上一个世界死得挺体面的。八十二岁，躺在床上，床头柜上摆着一碗子孙孝敬的鸡汤。系统管这叫圆满。我说这叫熬死了。

**越惨的事越要笑着说。**读者笑完之后，自己会后背发凉。这是沙雕爽文的命门，也是它比正经虐文更狠的地方。

**铁律二：系统是一个管劳资的领导，但正文里只写"一个声音"。**
不加性别、不加年龄、不加比喻、不写"像某某"——**全书对它一次形容都不给。**
它的官僚气全部靠台词自己说话：敬语、方括号、编号、"已上报"、"请宿主配合"。
> 【亲，您的节点——被继母毒打——已完成。祝您愉快。】
语调不变，本身就是笑点。**系统越客气，读者越想笑。**

**铁律三：她钻的是"节点定义"的空子，不是拒绝执行。**
剧本写"女主被继母毒打"，她不躲，她走过去把继母按住打完了。
系统记录：【节点·毒打 · 已完成 ✓】
**剧本只规定发生什么事，不规定谁对谁。这就是她全书的武器。**

**铁律四：每个世界的收尾必须是"节点全过、结果全崩"。**
这是每个世界的固定收束：她一丝不差地走完剧情，然后剧本想成全的那些人，一个都没落着好。
**读者每个世界都爽一次，而且永远猜不到她怎么爽。**

**铁律五：前任女主的痕迹，只给一个物件、一句话，不许写回忆长篇。**
一个洗好的碗、一道指甲划痕、一本写到一半的日记、一件没带走的旧衣服。
**她看一眼，说一句吐槽，然后收起来。**不许煽情——这本书的眼泪全部要用笑来兑付。

## 禁止清单

- ❌ 不许写她半夜哭、不许写她梦见上一世、不许写她"终于被理解了"。**她是王昭帝，她没空。**
- ❌ 不许给任何一个施害者写"人性的复杂"。这本书里的坏人就是坏人，打起来才爽。
- ❌ 不许写系统被她说服、被她的道理感化。**系统到死都是那副客服腔。**
- ❌ 不许给系统任何形容——不写它的性别、语调、像谁、什么感觉。**它永远只是"一个声音"。**
- ❌ 不许让观众露脸、说话、给弹幕。他们只在世界结束后改方案——**这个"沉默"是全书最大的压迫感来源。**
- ❌ 不许在结尾加"她终于自由了"这类升华句。最后一笔必须是一个动作。
- ✅ 她的名字要当成固定笑点反复用：系统每进一个世界派一个苦情剧标配名（招娣、淑贞、婉君、小怜、翠儿），她一次都不认，每次都自我介绍"王昭帝"。
- ✅ 她的自称可以是"朕"。但**要克制**——一本 35 万字的书，"朕"用多了就腻。建议每个世界不超过三次，且只在最帅的那一刻用。
- ✅ 前任女主这条线是全书唯一不搞笑的部分。**正因为其他部分全在搞笑，它才显得重。**

## 和扶华原作的关系（自己心里有数就行）

我们借的是**类型和机制**：快穿 + 系统强制 + 苦情剧世界 + 女主拒绝按剧本走。这是公共的类型财富。

但**人物、系统、观众、过关规则、金手指、结局，全部是我们自己的**：

| | 扶华《戏精穿进苦情剧》 | 本书 |
|---|---|---|
| 女主来历 | 被系统抓来 | **她本身就是被苦情剧害死的人** |
| 女主名字 | 水银 | 王昭帝（自己取的） |
| 反抗动力 | 性格张扬 | **性格 + 她已经知道结局** |
| 反派 | 苦情剧逻辑 | **幕布后沉默的观众 + 一套会自我修正的评估机制** |
| 金手指 | 无 | **看得见前任女主的痕迹** |
| 结局 | 自由篇，跳下游轮 | **规则自相矛盾，系统自崩，观众席是空的** |

**同一个类型，不同的答案。这就够了。**
