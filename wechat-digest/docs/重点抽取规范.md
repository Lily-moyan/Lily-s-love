# 聊天重点抽取规范 v1

这是所有会话摘要的统一标准。摘要质量的上限由本规范决定，**不是由模型能力决定**——
没有规范的摘要一定是流水账。

---

## 一、抽取值（按优先级）

### P0 · 需要我行动的
- 明确 @我、点名向我提问
- 别人请我帮忙 / 等我的答复
- 我承诺过但还没做的事
- 有 deadline 的事

### P1 · 结论与决定
- 明确给出的结论、判断、推荐（例如"X 不如 Y""这个方案可行"）
- 讨论中形成的共识或否定性结论
- 对工具/产品能力的实测反馈（是否可用、额度、价格、限制）

### P2 · 资源与信息
- 分享的链接、文章、报告、PDF、视频号内容
- 新发布 / 新版本的可用性变化
- 价格、订阅、额度相关的经验（这类信息价值高、时效性强）

### P3 · 时间地点与事件
- 约定、活动、聚会、报名
- 施工/交付/会议时间

### P4 · 未决争议
- 有人提出但没人给答案的问题（**这是"下一个动作"的候选**）
- 明显分歧且未收敛的观点

---

## 二、排除项（不要写进摘要）

- 纯表情、无文字的图片/视频
- 寒暄、语气词、单纯捧场（"好厉害！""[强]"）
- 系统消息（入群、撤回、拍了拍）
- 与话题无关的闲聊吐槽——**除非它是本群当期的主要话题**
- 重复刷屏内容（同一内容多次出现只记一次）

> 判断标准：**"我三天后再看这条，还会觉得有用吗？"** 不会就不写。

---

## 三、输出格式（Markdown）

```markdown
# <会话名> 摘要 · <起止日期>

## 一句话概览
<2-3 句说清这段时间群里主要在聊什么、有没有需要我关注的事>

## 关键结论
- <结论> —— <时间> <发言人>（<依据/上下文>）

## 值得看的资源
| 类型 | 标题 | 分享人 | 时间 |
|---|---|---|---|

## 主要观点与人
- **<姓名>**：<他的立场/主张，1-2 句>

## 待我处理
- [ ] <具体动作> —— 来源：<时间> <发言人>
（本群此窗口内没有涉及我的内容时，明确写「无」，不要编造）

## 数据统计
消息数 / 活跃人数 / 我发言数 / 时间跨度

## 未覆盖与存疑
- 图片内容无法读取（共 N 张），仅能确认存在
- 其他数据局限
```

---

## 四、硬性约束

1. **禁止编造**。只写导出记录里真实出现的内容。拿不准就写"不确定"。
2. **引用必须带时间与发言人**。没有出处的结论不可接受。
3. **区分"事实"与"我的归纳"**。归纳要建立在多条记录之上。
4. **图片/视频内容不可读**（本工作区没有解密 DAT 图片）：只能标注其存在，
   不得推测图片里说了什么。
5. **不做人格评价**，不输出与工作总结无关的隐私内容。
6. 我（wxid_pysr0b0aplrs21）发言为 0 时，不要虚构"我参与了讨论"。

## 五、数据来源与工具链

| 环节 | 工具 |
|---|---|
| 备份 | `robocopy` 拷贝 `db_storage`（含 `-wal`/`-shm`） |
| 取明文库 | `tools/find_key_v2.py` → `tools/decrypt_db.py` → `tools/merge_wal.py` |
| 会话映射 | `tools/map_conversations.py` → `out/conversations.json` |
| 导出正文 | `tools/export_conversation.py --name <会话> --days N` → `out/exports/*.txt` |

导出文本的格式约定：

```
===== 2026-10-08 =====
[09:12] 张三: 正文
    [@我] 被点名的那条
[14:37] 李四: 回复内容  ↳引用 王五: 被引用的原文
```

- `[@我]` = 明确点名我；`[@]` = 点名了别人
- `[图片]/[分享]/[文件]` = 非文本消息类型
- 缩进且无时间戳的行 = 同一人 5 分钟内的连续发言
