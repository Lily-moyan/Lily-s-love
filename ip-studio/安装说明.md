# ip-studio（文案工坊）安装说明

## 它是什么

多用户自媒体文案生成系统。流程：**账号设定 → 给一个题材 → 出 3 个差异化话题方向 → 选一个 → 流式生成完整成稿 → 编辑器里划词改写 → 确认后喂回账号学语气**。另带**热点**板块（抓榜单 → 和账号比对 → 找可蹭的点）、成稿检查、口播提示、管理后台（`/admin`）。

## 装在哪儿

| 项 | 值 |
|---|---|
| 安装目录 | `G:\dsh\ip-studio` |
| 源码来源 | `G:\浏览器下载\ip-studio-main.zip` |
| 服务地址 | http://localhost:5177 |
| 管理后台 | http://localhost:5177/admin （首次访问时在页面上创建管理员） |
| 数据文件 | `G:\dsh\ip-studio\data\app.db` （SQLite，Node 内置 `node:sqlite`，无外部依赖） |
| 依赖 | 仅 `@anthropic-ai/sdk` 一个包（走 OpenAI 兼容通道时用不到，但代码会 import） |

## 启动方式

- 双击 **`启动.bat`**（关闭窗口即停止），或
- 命令行：`cd /d G:\dsh\ip-studio` 然后 `node server/index.js`

首次打开先在页面上注册一个账号即可使用。

## 模型通道

`.env` 已配好 **DeepSeek**（OpenAI 兼容接口），密钥取自本机 harness 凭据里的 `DEEPSEEK_API_KEY`：

```
LLM_PROVIDER=openai
OPENAI_API_KEY=sk-****              # 见 .env，勿外传
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat
```

想换别的通道只改 `.env`：Claude 填 `ANTHROPIC_API_KEY`；Kimi / 通义 / vLLM / Ollama 改 `OPENAI_BASE_URL` + `OPENAI_MODEL`；清空密钥即回到**演示模式**（本地模板，全流程照样跑通）。

配图默认 `IMAGE_PROVIDER=mock`（本地占位图）；要真图可填 `DASHSCOPE_API_KEY` 走通义万相。支付默认 `PAY_PROVIDER=mock`（本地假支付），上线才需要企业主体和已备案域名。

## 安装时验证过的内容

1. `npm install` 装好 3 个包（用工作区缓存 `G:\dsh\.npm-cache`，因为系统默认 npm 缓存在沙箱外）。
2. Node v24.9.0 → `node:sqlite` 可直接用（仅有一条 experimental 警告）。
3. 用一次性实例（5188 端口 + 独立 db）跑通注册 → 生成话题方向：**HTTP 200，3 个方向，耗时 6.0s**，走的是真实 DeepSeek，不是演示模板。测试数据已随实例删除，正式库干净。

## 注意事项

- 服务是本会话前台启动的后台任务，**会话结束后会停**；日常使用请用 `启动.bat`。
- `server/db.js` 用的是 `node:sqlite`，需要 Node ≥ 22.5；低版本请升级 Node。
- 密钥只写在 `.env`（已在 `.gitignore` 里），页面/后台里填的商户私钥由 `SECRET_KEY` 加密入库 —— 上线前记得给 `SECRET_KEY` 设一个随机长串，且不要和数据库一起备份。
