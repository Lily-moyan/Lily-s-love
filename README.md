# 行业分析工作台

单文件 Web 应用：输入一个行业名称，按固定的五步 prompt 链，自动生成一份带**证据分级（A/B/C）**的行业分析报告。原生 HTML/CSS/JS，无构建、无后端、无第三方库，浏览器直连 DeepSeek API。

## 快速开始

1. 双击打开 `index.html`（或放到任意静态服务器）。
2. 点右上角 **⚙ 设置**，填入 DeepSeek API Key。
3. 顶部输入行业名称，点「开始分析」。

## 工作流

- **Step 0 边界切分** — 模型给出 2~4 个产业链结构明显不同的候选边界，可单选或交叉组合。
- **Step 1 结构层** — 产业链分层表（层级 / 干什么 / 代表公司 / 靠什么赚钱 / 收入确认时点 / evidence）。
- **Step 2 三条流转链** — 钱流 / 货流 / 用户流 + 三条链的错位。
- **Step 3 议价能力** — 五问，每个答案必须是可验证的量。
- **Step 4 约束/节奏/异常** — 全 C 档假设 + 验证方法 + 你还不知道的 10 件事。
- **Step 5 从业者拷问（可选）** — 模型扮演 12 年从业者，15 轮后给诊断。

## 特性

- 每个事实字段带 **A / B / C 证据标签**：A 档必须检索到具体文件名 + 年份，检索不到自动降级为 B 档或「未获取」。
- 流式渲染 Markdown、实时 token 用量（输入 + 输出）、检索次数统计、导出 `.md`。
- `web_search` 工具循环（浏览器端轻量检索，以维基百科等公开源为主），每步最多 10 次。

## 接口

- 端点：`POST {BaseURL}/v1/chat/completions`（默认 `https://api.deepseek.com`）。
- 认证：Bearer（默认）或 `x-api-key`，在设置里三选一。
- 模型：`deepseek-chat`（默认）/ `deepseek-reasoner`，可自由输入任意模型 ID。

## 注意事项

- API Key 只保存在本机浏览器 `localStorage`。
- 浏览器直连若被 CORS 拦截，可在设置里填「CORS 代理前缀」。
- `deepseek-reasoner` 的思考过程会以可折叠「思考过程」展示。
