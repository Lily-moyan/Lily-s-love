行业分析工作台

输入行业名称，点「开始分析」。模型先切分产业链边界，你选定后自动跑完四步，再可选「从业者拷问」。

  1. Step 0 · 边界切分 —— 2~4 个候选边界，选一个或交叉组合
  2. Step 1 · 结构层（产业链分层表）
  3. Step 2 · 三条流转链（钱流 / 货流 / 用户流 + 错位）
  4. Step 3 · 议价能力（五问，答案必须是可验证的量）
  5. Step 4 · 约束 / 节奏 / 异常 + 你还不知道的 10 件事
  6. Step 5 · 从业者拷问（可选，15 轮后给诊断）

每个事实字段带 A / B / C 证据标签；A 档需检索到具体文件名 + 年份，检索不到一律降级。

⚙ 设置

deepseek-chat 最大输出 8K；deepseek-reasoner 可到 32K。设太高会报错，以模型实际限制为准。

启用 web_search 检索工具（标 A 档前先核实）

API Key 仅保存在本机浏览器 localStorage，请求直连 DeepSeek。检索为浏览器端轻量检索（维基百科等公开源，覆盖有限，检索不到原始出处会按规则降级）。使用第三方 CORS 代理时，Key 会经过该代理，请只用你信任的代理。
