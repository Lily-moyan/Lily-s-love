# AI 产品经理工作台

一个面向 AI 产品经理和相关业务人员的 Web 应用，帮助围绕具体项目完成需求分析、AI 方案设计、PRD 草稿和竞品分析等工作。

## 功能特点

### 1. 项目管理
- 创建、编辑、删除项目
- 项目背景信息管理（业务对象、目标用户、当前阶段等）
- 项目间切换，数据完全隔离
- 数据自动保存到本地浏览器

### 2. 五种任务类型
- **智能识别**：自动判断适合的交付物类型
- **需求分析**：生成需求分析文档
- **AI 方案设计**：设计 AI 解决方案
- **PRD 草稿**：生成产品需求文档
- **竞品分析**：生成竞品分析报告

### 3. 工作流集成
- 支持连接 Coze 工作流
- 安全存储个人访问令牌 (PAT)
- 实时任务状态显示
- 完整的错误处理

### 4. 结果管理
- 格式化的业务文档展示
- 支持复制、编辑、保存、重新生成
- 证据与假设查看
- 版本历史管理

### 5. 用户体验
- 专业的视觉设计（深梅紫色 + 亮紫色）
- 响应式布局（电脑 + 手机）
- 示例文本快速填充
- 演示数据首次体验

## 使用方法

### 1. 打开应用
直接用浏览器打开 `index.html` 文件即可使用。

### 2. 配置连接（首次使用必需）
1. 点击左侧"连接设置"或顶部"连接设置"按钮
2. 输入您的 Coze 工作流 ID：`7676832175183282239`
3. 输入您的 Coze 个人访问令牌 (PAT)
4. 点击"测试连接"验证配置
5. 点击"保存配置"

### 3. 创建项目
1. 点击左侧"+"按钮或顶部"新建项目"按钮
2. 填写项目信息：
   - 项目名称（必填）
   - 业务对象
   - 目标用户
   - 当前阶段
   - 已确认范围
   - 关键约束
   - 待确认事项
3. 点击"创建项目"

### 4. 执行任务
1. 选择任务类型（智能识别、需求分析等）
2. 在输入框中描述您的业务需求
3. 点击"开始分析"
4. 等待任务完成
5. 查看结果文档和证据

### 5. 管理结果
- **复制全文**：复制结果到剪贴板
- **保存到项目**：保存到当前项目
- **继续编辑**：修改结果内容
- **重新生成**：再次执行当前任务
- **继续下一项**：跳转到下一类任务
- **查看证据**：查看分析依据和假设

## 技术特点

### 纯前端实现
- 无需后端服务器
- 使用 localStorage 进行数据持久化
- 所有数据保存在本地浏览器中

### 安全性
- 个人访问令牌使用安全方式存储
- 保密信息不会出现在页面结果中
- 提供安全警告提示

### 响应式设计
- 电脑端：三栏布局（项目区 + 工作区 + 证据区）
- 手机端：单栏布局，侧边栏可收起

## 注意事项

1. **数据安全**：
   - 请勿输入未经授权的个人信息、商业秘密或生产凭证
   - 建议定期备份重要数据

2. **工作流配置**：
   - 确保工作流 ID 和访问令牌正确
   - 访问令牌需要有相应权限

3. **浏览器限制**：
   - 使用 localStorage 存储数据，清除浏览器数据会丢失项目
   - 不同浏览器之间的数据不互通

4. **演示数据**：
   - 首次打开时会显示演示项目
   - 演示数据明确标注，不会与真实结果混淆

## 常见问题

### Q: 数据保存在哪里？
A: 数据保存在浏览器的 localStorage 中，不会上传到任何服务器。

### Q: 如何备份数据？
A: 可以使用浏览器的开发者工具导出 localStorage 数据。

### Q: 为什么无法连接工作流？
A: 请检查：
1. 工作流 ID 是否正确
2. 访问令牌是否有权限
3. 网络连接是否正常

### Q: 如何删除演示项目？
A: 选择演示项目，点击"编辑背景"，然后点击"删除项目"。

### Q: 支持多语言吗？
A: 目前仅支持中文界面。
