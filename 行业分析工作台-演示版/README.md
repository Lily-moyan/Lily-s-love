# 部署说明：把行业分析工作台变成面试官能点开的链接

## 这个文件夹是什么

一个**纯静态 PWA** 作品集页面，已内置：

| 功能 | 说明 |
|---|---|
| **首屏说明卡** | 面试官一打开就知道这是什么产品、解决什么问题、三个核心机制 |
| **演示模式** | 点「▶ 看演示」→ 播放预置示例（**明确标注"未调用模型"**），不需要任何 API Key |
| **真实运行** | 点「⚙ 设置」填自己的 DeepSeek Key → 可实际跑完整流程（Key 只存本地浏览器） |
| **PWA（可安装）** | 手机上「添加到主屏幕」后全屏运行、有图标、可离线看演示 |

**为什么必须有演示模式**：面试官不会为了看你一个作品去注册 API Key。
没有演示模式 = 打不开 = 零作品。

## 文件清单

```
index.html              主页面（含演示模式 + PWA 注入）
manifest.json           PWA 应用清单（名称/图标/standalone 模式）
sw.js                   Service Worker（静态资源缓存，API 请求不接管）
icon-192.png            图标 192 —— 圆角透明，purpose: any
icon-512.png            图标 512 —— 圆角透明，purpose: any
icon-maskable-512.png   图标 512 —— 满幅无透明角，purpose: maskable
apple-touch-icon.png    iOS 图标 180 —— 满幅无透明角
README.md               本文件
```

**为什么图标要分两套**（这是很容易踩的坑）：

| 类型 | 要求 | 踩错的后果 |
|---|---|---|
| `any` | 可以圆角透明 | — |
| `maskable` | **背景必须满幅、不能有透明角** | 系统把图标裁成圆形/水滴形时，透明角会露出来，边缘出现锯齿或黑洞 |
| `apple-touch-icon` | **必须满幅** | iOS 会自己切圆角；透明背景会被渲染成**黑底** |

本包的 maskable 与 iOS 图标都做了满幅处理，且内容落在**中心 80% 安全区**内（实测最远角距中心 189.6px < 安全半径 204.8px），所以在任何裁切形状下都不会被切到。

**部署时把整个文件夹拖上去**，这 8 个文件缺一不可（少 `manifest.json` 或 `sw.js`，PWA 就退化回普通网页）。

## 部署方式一：Netlify Drop（最简单，不用命令行、不用 Git）

1. 打开 https://app.netlify.com/drop
2. 把**整个文件夹**拖进页面（拖文件夹，不是拖 index.html）
3. 等几秒 → 得到一个 `https://xxx.netlify.app` 链接
4. 在 Netlify 后台可以把站点名改成好记的，例如 `ai-industry-analysis-<你的名字>`

> 免费额度足够个人作品集。首次使用需要邮箱注册（免费）。
> **Netlify 自动提供 HTTPS**——这是 PWA 能装到主屏幕的前提。

## PWA 怎么验证装成功

部署完成后，**用手机**打开链接：

**Android（Chrome / Edge）**
- 页面上会出现「📱 添加到主屏幕」引导条 → 点按钮 → 确认
- 或浏览器菜单 →「安装应用」
- 装好后从桌面图标打开：**没有地址栏、全屏，和原生 App 一样**

**iOS（Safari）**
- Safari 不支持自动安装提示，页面会显示「查看安装方法」
- 点它，或手动：**分享按钮 → 添加到主屏幕 → 添加**
- ⚠️ 必须用 **Safari**，微信内置浏览器和 Chrome iOS 都不支持

验证要点：
- [ ] 桌面出现图标，且图标不是白块（是深底 + 绿/蓝/灰三条）
- [ ] 点图标打开后**没有浏览器地址栏**
- [ ] 断网后再打开，**演示模式仍可播放**（Service Worker 缓存生效）
- [ ] 真实调用模型时断网会失败——这是正常的，API 请求不缓存

## 一条必须遵守的原则

> **可达性优先于炫技。**

默认走 DeepSeek（OpenAI 兼容协议），**故意没有**默认用国外模型服务——
因为如果面试官在你的页面上打不开、转圈、超时，**你不会知道自己是因此被刷的**。

想展示"我也用国外模型"，正确做法是：**默认路径保证可用**，另设可选切换说明，
而不是把默认路径设成需要特殊网络才能走通的那条。

## 关于「要不要做成真 App」

**如果目的是面试作品集：不要做 App。** 面试官不会为了看你作品去下载安装——
PWA 已经能做到"装到主屏、全屏、有图标"，而它**零成本、零审核、零合规**。

**如果目的是当产品发布给用户**，才需要真 App，但要算清门槛：

| 路径 | 工作量 | 钱 | 门槛 |
|---|---|---|---|
| **PWA（当前）** | 已完成 | 0 | 无 |
| Android APK 套壳 | 半天 | 0 | 需 Android 构建环境；自己装/发群可以，**上架商店要软著+备案** |
| 国内应用商店上架 | 数周–数月 | 软著费用 | **软件著作权证书**（1–3 个月）+ **App 备案**（工信部强制）+ 各商店类目审核 |
| iOS | 数天 | $99/年 | 需要 Mac + 开发者账号 + 审核 |

> 同一份 `index.html` 可以用 **Capacitor** 直接套壳成 Android APK
> （`npm i @capacitor/core @capacitor/cli` → `npx cap init` → 把本文件夹设为 `webDir` → `npx cap add android` → 用 Android Studio 打包）。
> 但**先上 PWA**——它能立刻用，而且是 APK 的前置步骤。
