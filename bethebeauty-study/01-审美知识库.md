# BeTheBeauty（简妮）审美知识库

> 这是把该号方法论**去人化、结构化**的结果：去掉明星八卦的壳，留下可迁移的分析框架与判定规则。
> 使用方式：整篇可作为领域知识上下文喂给模型；也可在写稿时只取其中一节。

---

## 第 0 层｜底层世界观（她所有文章共享的 8 条信念）

这 8 条是理解一切具体结论的钥匙，**仿写时若不遵守这 8 条，文风再像也不是简妮**。

1. **美是相对概念，不是绝对值。**
   所以不说"我眼睛太小"，而说"我眼睛**相对于 X** 来说太小"。判断任何一项都要先找到参照物。
2. **比例思维：不要孤立地看一个部位，看关系。**
   单看一条线无法判断长短；单看一个五官无法判断好坏。一个部位的变化会牵动 ABC 三处观感。
3. **「好看」与「舒服」是两件事，来自两个视角。**
   - 只看**五官特写**（五官之间的关系）→ 主要影响**好看程度**；
   - 看**全脸**（五官与脸型的搭配）→ 主要影响**舒服程度**。
   一个人可能特写好看、全脸别扭，也可能相反（如"特写好看但下巴偏长"型）。
4. **浓淡 ＝ 内容 vs 留白。**
   脸是容器，五官大小、颜色浓淡、轮廓鲜明度都是往容器里放的"内容"。内容少＝淡，内容多＝浓。
5. **平衡优先，拒绝走极端。**
   不是越浓越好、越标准越好、越完美越好。攻击性太足、太挤、太腻都会变丑。
6. **目标是"适合自己 + 有辨识度"，不是"变成标准脸"。**
   "淡本身也是一种风格，关键是**淡而有味、淡而有辨识度**，而不是寡淡。"
7. **美 ＝ 硬件 × 造型 × 语境。**
   文化评论类文章会把这个升维：美人需要好的造型、好的音乐、好的故事；"因人杰出，故而地灵"。
8. **方法上追求"四两拨千斤"与"扬长避短"。**
   能修正的修正，不能修正的**弱化**，再把美的一面放大。反对蛮力自律、反对照抄他人方案（明星有反馈强度、自律水平、外力支持三重差异，普通人抄不了）。

## 第 1 层｜标准分析流程（六步，可直接套用到任何一张脸上）

**Step 1 拆解硬件**
眼型/眼距/瞳距、鼻长/山根高低、唇形/唇谷、眉形/眉头/眉峰、脸型轮廓（骨相 vs 皮相）、上/中/下庭长度。

**Step 2 找关系（比例诊断）**——这是她的核心竞争力，四个必查项：
| 关系 | 怎么看 | 结论方向 |
| --- | --- | --- |
| 眉眼距 | 与"一只眼的高度"比 | < 一只眼 → 紧凑；> 一只眼 → 分散 |
| 眉眼距 vs 人中长 | 两者是否接近 | 接近 → 舒服均衡 |
| 山根高度与鲜明度 | 山根低/不鲜明 | 五官显得更"散"（横向紧凑度下降） |
| 眼距 / 瞳距 | 偏近或偏远 | 决定妆容重心靠内还是往两侧拉开 |

**Step 3 浓淡诊断（四因子）**
`大小` × `颜色` × `轮廓` × `比例` → 综合判断这张脸是偏浓、偏淡还是中间。
关键推论：**紧凑的比例本身有"加浓"效果**（把视觉冲击力集中）；分散则有"减淡"效果。

**Step 4 全脸校验（舒服度）**
把特写结论放回全脸：五官分布过高/过低/过集中/过分散，都会破坏舒服感。

**Step 5 定性（风格定位）**
给出这张脸的"类型坐标"：浓颜 / 淡颜、骨相脸 / 皮相脸、成熟感 / 减龄感、清秀 / 明艳 / 风情 / 精英。

**Step 6 给方案（加 or 减）**
- **淡颜 → 做加法**：扩大五官、减少五官间留白、提高颜色鲜明度、让比例显得更紧凑（挑眉、双眼皮贴、大面积眼影、山根鼻影、上唇高光、涂满唇谷缩短人中）。
- **浓颜 → 做减法**：让五官视觉上更分散、留出**视觉缓冲**、减少颜色与轮廓堆叠；避免用大面积眼影/腮红/发型继续挤占留白。
- 提醒：**柔和轮廓/骨相脸**很难靠化妆大幅增加轮廓感，也**不适合**温和日系妆，硬上会"两头不搭"。

## 第 3 层｜判定规则与经验结论（可直接引用的断言）

> 以下均为该号文中明确给出的"标准"。引用时建议注明来源；沿用前请自行判断是否仍成立。

**比例类**
- 眉眼距 **≈ 一只眼的高度** 为参考标准；小于＝紧凑，大于＝分散。
- **眉眼距 ≈ 人中长** 时最舒服均衡；两者可都短（更紧凑，如叶蕴仪型）或都长（更分散，如谭松韵型），只要相等即可。
- 中庭长 → 显成熟（偏上中庭随年龄增长易显老）；中庭短 → 显减龄（常伴随塌鼻梁）。
- 上庭长而饱满 → 显年轻；下庭长 → 显成熟；**五官整体靠下 → 显年轻**。
- 下唇线宜位于下巴的 **1/2** 处。
- 三庭五眼的两个真正研究对象是：**五官的大小** 与 **五官的位置/分布**；其缺陷是"要画线才直观"且受**视觉错觉**干扰（眼距未变却看起来更宽）。

**浓淡类（核心比喻）**
- 五官浓 + 比例紧凑 ＝ 满汉全席后再吃烤全羊再吃大蛋糕 → **腻**。（例：后期李嘉欣，眉毛变挑、双眼皮变宽、山根抬高上移，愈发紧凑反而失去早期娇憨。）
- 五官淡 + 比例分散 ＝ 顿顿喝粥还 8 小时才吃一次 → **又淡又寡**。（例：孟美岐，靠挑眉＋双眼皮贴＋大面积眼影＋山根鼻影＋上唇高光把脸"调浓"。）
- 浓颜需要**更分散**的比例来调和，浓妆时往往**仰头**更好看；淡颜/五官偏小者**低头**可缩短眉眼与人中距、比例更紧凑。

**操作类**
- 调整比例的三条思路：①**改五官形状**（幅度小，受硬件限制）；②用妆容**视觉挪动**五官位置（纵向：重上轻下或反之；横向：眼距近→妆容往两侧分散）；③**增大五官 / 缩小留白**（眼影、卧蚕、腮红、鼻影）。
- 拉近眉眼距的两招：**加粗眉头**、在**眉头下方加阴影**（如安室奈美惠；国内常见于"晚晚"）。
- **仰头 → 比例分散；低头微笑 → 比例紧凑**（最简单的自测/拍照口诀）。
- 五官不对称可微调：眼睛偏高的一侧"下眼妆粗、上眼妆细"，偏低的一侧反过来。
- 体态类（近期文章）：身材问题多数**不是太胖而是太没型**；肩颈有型 > 胖瘦；危害最大的是**颈前伸**与**手前伸**（圆肩驼背、背厚显胖、咬合/头痛/垮脸），以及**坐姿太靠后**导致的"妈妈臀"。
- 放松类：长期"交感神经过度激活"（易怒、紧绷、入睡难、吃不饱）可通过按摩/放松转入副交感主导态——这是"明星状态好"的隐藏变量。

## 第 5 层｜选题库（可复用的 7 个母题）

1. **反常识纠错型**：「只靠三庭五眼还想变美？X 都被坑丑，这新标准才是救星！」
   → 立一个旧标准当靶子，给一个新标准。
2. **新旧标准对撞型**：先肯定旧理论的价值与贡献，再逐条指出缺陷（不直观、受错觉干扰、只看五官与脸型联动），最后补上缺失的视角。
3. **明星复盘型**：选"越来越美"或"越来越怪"的明星，用同一套框架解释前后差异，得出可迁移结论。
4. **单部位深挖型**（最稳的系列做法）：眉眼距、人中、贴骨眉、山根、卧蚕、脸型……每篇给定义→图例→标准→方法→预告下一篇。
5. **日常低成本型**：「别死磕自律了」——从坐姿、玩手机姿势、按摩入手，先破除"必须高强度"的焦虑，再给懒人方案。
6. **文化/时代评论型**：从一个审美现象（港风、港姐、整容脸）上升到文化解释与价值判断，结尾落回"精气神"。
7. **素人改造型**：真实案例前后对比（该号此栏目口碑一般，属可做但需谨慎的一类）。

**选题配方**（把任意热点转成本号选题）：
`当红人物/现象` + `流行做法或流行理论` + `它的破绽` + `我补上的新视角` + `可带走的判断标准`

## 第 6 层｜一页速查（写稿时贴在旁边）

```
拆解 → 关系 → 浓淡 → 全脸 → 定性 → 加减法
关系四项：眉眼距(≈一只眼) / 眉眼距vs人中长(≈相等) / 山根鲜明度 / 眼距瞳距
浓淡四因：大小 · 颜色 · 轮廓 · 比例(紧凑=加浓)
两句口诀：淡颜做加法+更紧凑；浓颜做减法+更分散
一个比喻：浓+紧凑=吃腻；淡+分散=寡淡
一条纪律：先讲清原理，再给方法；先给标准，再给例外
```
