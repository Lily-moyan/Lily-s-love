# 公众号发布信息包 ·《别急着花三万块学「造AI」了》

## 一、怎么发（两条路）

### 路线 A：复制粘贴（推荐，1 分钟）
1. 用浏览器打开 `排版稿.html`（双击即可）；
2. 在页面上 `Ctrl+A` 全选 → `Ctrl+C` 复制；
3. 打开公众号后台 → 新建图文 → 正文区 `Ctrl+V` 粘贴。
   → **不要复制 HTML 源代码**，一定要复制浏览器里渲染出来的页面，否则会粘出一堆标签。

### 路线 B：第三方编辑器
把 `纯文本稿.txt` 的内容导入秀米 / 135 编辑器再套模板；`纯文本稿.txt` 已去掉所有 Markdown 符号（没有 `**` 和 `##`），可以直接粘。

### 路线 C：API 直发（需要你的凭据）
公众号有「新增草稿」接口（`draft/add`），可以做到一键生成草稿箱。
**需要**：① 该号的 AppID 与 AppSecret；② 把调用方的公网 IP 加入后台 IP 白名单；③ 已认证的服务号/订阅号权限。
**注意**：凭据是敏感信息，请放进本地环境变量或配置文件，不要直接贴在对话里。你要走这条路，告诉我"走 API"，我来写脚本和说明。
