## 一、账号档案（事实层）

- **账号名**：BeTheBeauty（ID：`bethebeauty`）；主笔自称**简妮**，行文中最常见的自称是「简妮我」，另印署名「胖达简妮」。
- **商业联系**：`bethebeauty@sina.com`（早期文章文末固定露出）。
- **起点与轨迹**：从**知乎**起家（"没看过这篇，别说你了解你的脸"系列、"三庭五眼"批判系列，约 2015—2016 年），后以**微信公众号**为主阵地，同时被搜狐号、网易号、今日头条、Flipboard 等大量转载分发；至今仍在更新（2026 年仍可见新文）。
- **定位**：**审美科普型**变美干货号，不是化妆教程号。特点是「先讲清原理，再给方法」，强调**找到适合自己的风格**而非追潮流。
- **内容域**：五官与比例 → 脸型 → 浓淡颜 / 风格气质 → 妆容（眉形、眼妆、人中、山根）→ 发型 → 体态与姿势 → 抗老 → 明星颜值变迁复盘 → 审美文化评论（港风、时代审美）。
- **称呼体系**：把读者叫「老读者」「聪明的读者」「特别老的读者」——一种建立长期陪伴感的身份标记。
- **商业化路径**：广告软植入 → 素人改造栏目 → 知识星球等付费社群 → 付费训练营（如"胖达简妮沟通力成长营"）→ 自有产品植入（如按摩/体态相关）。
- **读者画像**：以女性为主，诉求不是"教我化妆"，而是"帮我判断我这张脸该怎么走"。

## 二、公开评价（用于知道该学什么、不该学什么）

正面：理论扎实、能帮人定位风格、讲妆容与亚洲女孩身材/骨架条件"算在理"。

批评（多次出现在豆瓣讨论中）：
1. **文章过长**，信息密度不均，"像沙里淘金"，很多人直接看总结；
2. **后期干货稀释、广告变多**（有自称实习助理的读者称"刚开始干货蛮多，现在广告贼多"）；
3. **结论强势**、"不太接受反驳"，善用"引导性用语"强化自己的理论；
4. 素人改造效果被质疑（"只是会化妆和不会化妆的区别"）；
5. 曾有**洗稿**争议。

→ 结论：**学框架 + 学文风，但要主动规避它的四个短板**（详见 `02` 的"禁忌"一节）。

## 四、使用与合规提醒

- 本包中的框架、词表、规则为**转述与结构化整理**，不是原文复制；引用的短句仅用于说明文风特征。
- 「模仿文风」＝学习句式、结构、论证节奏与比喻方式；**不等于**照搬原文句子或把她的观点改写成自己的文章（后者正是该号被指责的"洗稿"）。若要复用她的具体结论，请注明来源。
- 仿写产出建议自己过一遍事实核查：明星图例、比例数据、科学结论都需要另行验证。
