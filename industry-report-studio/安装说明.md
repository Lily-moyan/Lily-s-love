# 行业分析工作台 · 安装与使用

## 它是什么

由**文案工坊**改造而来的行业研究与报告撰写工作台。动线：

**设定研究对象**（体裁、研究范围、报告读者、要回答的核心问题、口径禁忌）
→ 给一个议题 → **出三个分析角度**（政策环境 / 技术路线 / 风险与不确定性…，维度互斥）
→ 选一个 → **流式生成报告正文**（结论先行、分节、标数据口径与来源）
→ 编辑器里划词改写（扩写论证 / 更严谨 / 补个佐证 / 压缩成要点…）
→ **两层检查**（语言与一致性 + 数据与口径 / 来源可核查 / 结论与证据 / 合规风险）
→ **资讯板块**（政策、宏观、采购、财经快讯、舆情，与本对象逐条比对）

## 怎么用得好

1. **研究对象要写实**。「要回答的核心问题」这一栏是整个流程的靶心，三个角度都围着它转；「口径与禁忌」里写清不许引用哪些数据源、什么算已生效政策，检查阶段会照着查。
2. **章节模板自带数据清单**。比如选「市场规模」章节时，会要求填「已知的规模数据（含年份与来源）」「统计口径」「推算假设」。这些是提示词里**唯一可信的事实来源**——填了就是硬约束，不填模型会写成「待验证假设」而不是编一个数。
3. **风险与不确定性那一节不要跳过**。体裁规范里强制要求给出成立条件与证伪信号，这是报告和宣传稿的分界线。
4. **检查结果里的「来源可核查」最值得看**。它会把没出处的数字、机构名、条款号点出来，但不替你判断真假。
5. **资讯板块**给的是标题（部分带摘要），引用前必须点开原文核实；没有摘要的条目，报告只会把它当一句由头。

### 一个实证：素材填不填，检查结果完全不同

同一议题跑了两次（草稿 1 与草稿 2）：

- **草稿 1 —— 素材里没给政策原文**（只写「暂无可引用的政策原文」）
  检查在「来源可核查/高」抓到：*正文中的政策文件全称、发布主体与年份均属自行补入*、*把未核实的文件直接定性为部门规章*。
- **草稿 2 —— 素材里给了真实政策的名称 + 文号 + 来源链接**
  编造类问题消失，剩下的 6 条变成判断强度问题：*证据不足时先下判断*、*把从链接路径推断出的月份标成「已确认」*、*概括性论断没有出处*。

结论：**你在素材清单里填什么，决定了模型能编什么**。填真事实，它就没得编；留空，它一定替你编一个。所以第一个研究对象请配一个你手里有真实材料（政策原文、财报、招投标公告、客户数据）的章节。
