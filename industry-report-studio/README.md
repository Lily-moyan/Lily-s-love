# 行业分析工作台（industry-report-studio）

从**文案工坊**（`G:\dsh\ip-studio`）改造而来：保留它那套「设定语境 → 出多个角度 → 选定后流式成稿 → 就地改写 → 两层检查 → 提示词运维」的引擎与多用户 SaaS 骨架，把「自媒体」那层产品知识整体换成**行业研究 / 报告撰写**。

原版代码与文档请见 `README.upstream.md`（保留未删）。

## 快速开始

```bash
npm install
node server/index.js          # http://localhost:5178
```

或双击 `启动.bat`（关闭窗口即停止）。

- 工作台：http://localhost:5178/app （未登录时访问 `/` 看到的是介绍页，登录后自动进工作台）
- 管理后台：http://localhost:5178/admin （首次访问时在页面上创建管理员）
- 提示词说明书：http://localhost:5178/prompts （只读展示实际下发的 system prompt）

需要 Node ≥ 22.5（数据层用内置 `node:sqlite`）。唯一的 npm 依赖是 `@anthropic-ai/sdk`，走 OpenAI 兼容通道时用不到它但代码会 import。

| 中国政府采购网·要闻 | 采购招投标 | 13 条 |

| 东方财富·快讯 | 财经快讯（带摘要） | 20 条 |
| 今日头条·热榜 | 舆情热度 | 20 条 |

- 每个源独立超时与容错，一个挂了不影响其它源；20 分钟内存缓存；UI 显示每个源的状态，并支持手动粘贴清单兜底。
- **已弃用**：gov.cn 政策文件库搜索接口实测返回空 `data`；36氪网关接口 500；财联社、虎嗅、钛媒体、巨潮、RSSHub 公共实例均不可达。
- 硬过滤（伤亡灾难、战争冲突、疫病、娱乐私人、点名争议）对所有源生效；但对**政策/宏观/采购**类源豁免「犯罪司法」与「点名争议」两条——政策标题里出现「违法」「处罚」是正常的。

## 自检结果（真实 DeepSeek 通道）

```
分析角度 : 200 (8.6s)  3 个 → [政策环境] / [技术路线] / [风险与不确定性]
报告正文 : 200 (14.9s) 4082 字，SSE 流式
报告检查 : 200 (7.3s)  判定 minor，语言问题 2 条，风险提示 7 条
  · [数据与口径/高] 核心判断给出的 IRR 波动区间与第二节结论严重不一致，两处均未交代测算口径
  · [来源可核查/高] 文件名被当作已生效政策引用，但未核实全文，条款编号与补偿标准缺失
  · [数据与口径/中] 套利收益推算未说明系统效率、损耗率、交易费用，过程不可复现
```

检查维度确实在抓报告特有的问题，而不是自媒体式的错别字。

## 目录

```
server/
  index.js      HTTP 服务与路由（node:http，无框架）
  routes.js     API 处理函数
  db.js         node:sqlite 数据层（表名沿用上游：personas / sections / drafts …）
  auth.js       scrypt + httpOnly cookie（业务与管理两套会话互不相认）
  llm.js        anthropic / openai(兼容) / mock 三通道
  prompts.js    ★ 全部产品知识：体裁规范、风格、主体与视角块、章节模板、各功能 system prompt 与 Schema
  hotspots.js   ★ 资讯源（8 个）与硬过滤规则
  images.js     出图接入层（图表建议目前走文生图）
  mock.js       演示模式模板
public/         前台单页（index.html + app.js）、后台（admin.html + admin.js），无构建步骤
```

改产品语义主要动两个文件：`server/prompts.js`（生成与检查）与 `server/hotspots.js`（资讯源）。

## 已知边界

- **图表建议走文生图**：`images.js` 仍调用文生图接口，生成的是插画不是数据图表。要真图表需要换成图表渲染；把 `IMAGE_PROVIDER=mock` 可以完全不花钱。
- **发布数据回流**模块仍是内容运营语义（阅读/点赞/评论/转发/订阅），只改了标签，没有重做成研究场景的指标跟踪。
- **演示稿（提词器）**保留匀速滚动，没有做跟读对齐。
- **营销页**（`/start` 的 promo.html、`landing.html`）只做了术语与平台名替换，文案未重写，公开投放前应重写或下线。
- 数据表名、API 字段名仍是上游的 `personas` / `drafts` / `platform` 等，没有做重命名——只改了中文语义与界面文案。`platform` 字段现在的含义是「报告体裁」。
- 会话存 SQLite，密码用 scrypt；生产部署需自行加 HTTPS、限流与注册准入。
- 管理后台只读，没有封号/调额度/加管理员的入口。
- 资讯源是非官方接口与页面抓取，站点改版即失效；原文正文大多抓不到，只有标题时报告只会把它当一句由头。
- 检查只**指出**没出处的数据，不判断真假，核实仍需人工。
