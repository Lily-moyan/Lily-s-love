# 每天一个小故事 · 背单词 APP

给 6 岁孩子的背单词 APP。**一天一个词、5 分钟、不考试。**
装到手机主屏幕后，全屏打开、离线可用、不联网、不上传任何数据。

---

## 一、为什么之前装不上（重要）

安卓 Chrome / Edge **只允许在 HTTPS 网站或 localhost 上安装 App**。
之前手机打开的是 `http://192.168.7.35:8765`（局域网明文 HTTP），所以浏览器直接拒绝安装 ——
这是浏览器的安全策略，不是 APP 的问题。

**解决办法：换成 HTTPS 打开。** 已经准备好了自带证书的服务器。

---

## 二、现在怎么装（3 步）

### 1. 电脑上启动 HTTPS 服务器

```powershell
cd G:\dsh\背单词APP
python serve.py
```

首次运行会自动生成自签证书，然后屏幕会打印手机要访问的地址，形如：

```
手机打开： https://192.168.7.35:8443
```

> 服务器保持开着（装的过程中需要）。装完之后手机离线也能用。
> ⚠️ 电脑重启或换了 WiFi 之后 IP 可能变，重新跑 `python serve.py` 看新地址；
> 如果 IP 变了，证书要删掉 `.certs` 目录重新生成。

### 2. 手机访问那个 https 地址

手机上打开 **`https://192.168.7.35:8443`**

会出现「**您的连接不是私密连接**」警告 —— 这是正常的（自签证书，只有你自己在用）：

- 安卓 Chrome：点「**高级**」→「**继续前往 192.168.7.35（不安全）**」
- 然后再进一次，地址栏会显示"不安全"，但页面正常

### 3. 安装到主屏幕

| 手机 | 操作 |
|---|---|
| **安卓 Chrome** | 右上角「⋮」→「**安装应用**」；或页面里的「📱 一键安装到主屏幕」按钮 |
| **安卓其他浏览器** | 菜单里找「添加到主屏幕」 |
| **iPhone** | **Safari** 打开 → 分享 ⬆️ →「添加到主屏幕」 |

装好后从主屏幕图标打开就是**全屏、无地址栏、离线可用**。

> APP 里「家长看这里」→「设置」第一行会显示**运行环境**，一眼就能看出现在装不装得了：
> - `运行环境：HTTPS` → 可以装
> - `运行环境：HTTP 局域网地址` → 装不了，按本文换成 https

## 三、孩子怎么用

每天打开，只有一件事：点**「开始今天 ✨」**，跟着走 5 步：

| 步骤 | 内容 | 谁做 |
|---|---|---|
| 1 | 读小故事（点 🔊 听，点 🎤 跟读这句） | 一起读，家长先读一遍 |
| 2 | 动一动（做那个动作） | 孩子做 |
| 3 | **考考你**（说意思 / 做动作） | **孩子说，家长别替答** ← 最关键 |
| 4 | **跟我读**（录下来和原音对比） | 孩子读，自己听 |
| 5 | 睡前想一想 + 贴星星 ⭐ | 孩子贴 |

首页下面还有「**今天再看一眼**」：自动挑出前 1 天 / 3 天 / 6 天学过的 3 个词，
重做一遍动作、说一声，点掉小方框就行。**不考试、不打分。**

## 三·五、跟读（录音对比）

第 4 步「**跟我读 🎤**」：先听原音（也能 0.7X 慢速听），再**按住大按钮**跟着读，
松开就停；然后来回听「听我自己」和原音，像不像由孩子和家长自己判断。

故事里的每一句也能单独跟读——点句子左边的 **🎤**，就会跳到跟读步骤专门练那一句。

### 这里有一个刻意的设计决定：**不做机器打分**

技术上完全可以接语音识别、给个分数。**但没有做**，原因：

- 语音识别对 **6 岁孩子**的发音误判率很高（口齿、连读、音量都会影响）
- 一旦弹出"❌ 读错了"，孩子会直接不想开口——**打击的是一个刚建立的表达欲**
- 这个年龄段真正有效的反馈是"**我读的和他读的像不像**"，这件事耳朵就能判断

所以这一版只提供**录制、回放、对比**，判断权交给孩子和家长。等孩子到 8–9 岁、
发音稳定了，再考虑加自动评测也不迟。

### 隐私

- 录音**只在手机内存里**，用完（重录、离开这一步、关闭学一学）就**立即释放**，
  连本地存储都不写入
- **不上传、不联网**，没有任何服务器能看到孩子的声音
- 每次进入跟读会**单独请求麦克风权限**，不给权限也不影响其他功能（按钮会变灰并说明原因）

### 使用前提

录音用的是浏览器的 `getUserMedia`，**只在 https 或 localhost 下可用**。
这也是必须用 `serve.py` 起 HTTPS 的原因之一（另一个原因是安卓装 PWA 必须 HTTPS）。
如果是 http 打开，跟读按钮会变灰并明确提示，不会静默失败。

## 五、这套设计为什么这么做

来自 `../gaokao-3500/轻松版/成祥方法适配规划.md` 的取舍结论：

| 保留 | 改动 |
|---|---|
| 词汇量优先，先堆词不急着上课 | 不学音标/拼读 → **改成**每张卡片带首字母发音（`help → h /h/`） |
| 只认脸不背拼写（阅读词汇 vs 写作词汇） | 英译汉优先 → **改成**声音↔动作优先，翻译等 9 岁后 |
| 拿笔留痕、不用 App 盯屏 → **纸质涂色 + 睡前不用屏** | 每天 15 分钟 → **改成** 5 分钟 |
| 睡前回忆（记忆固化最强） | 复习间隔 D+1/2/4/7/15 → **改成** D-1/D-3/D-6（6 岁忘得快） |

## 六、发音（已内置真人音频，含 0.7X 慢速）

APP 里每个单词、每句故事都带**微软神经网络音色（en-US-AriaNeural）**的发音，点一下就能听：

| 在哪里点 | 听到什么 |
|---|---|
| 首页的大单词 / 首字母发音条 | 这个单词的正常速发音 |
| 首页发音条右边的 **🐢 0.7X** | 这个单词的**慢速**发音 |
| 学一学第 1 步「🔊 读单词」/「🐢 0.7X」 | 正常速 / 慢速 |
| 第 2 步「🔊 再听一遍」/「🐢 0.7X 慢速」 | 正常速 / 慢速 |
| 第 3 步提示音 | 正常速 |
| **点故事里的任意英文句子** | 那一句的完整朗读 |
| 「今天再看一眼」里的 🔊 / 🐢 | 正常速 / 慢速 |

**0.7X 慢速是怎么实现的**：不是把正常音频减速播放（那样会失真），而是
**另外生成了一整套慢速音频**（语速参数 `-40%`，约等于正常语速的 0.7 倍），
音质和正常速一样干净。同时播放器也设了 `playbackRate = 0.7` 作为兜底。

- **离线也能听**：**180 个音频**（30 正常速 + 30 慢速 + 120 句子）在装 App 时就一起缓存进手机。
- **不叠音**：换一个音频会自动停掉上一个。
- **兜底**：万一某个音频坏了，会自动退回手机自带的语音朗读，不会哑掉。

### 想重新生成 / 换音色 / 改慢速倍率

先把 `edge-tts` 装到工作区（不写系统目录）：

```powershell
$env:UV_CACHE_DIR='G:\dsh\.uv-cache'
uv pip install --target 'G:\dsh\.tts-libs' edge-tts
```

再生成（只补缺失的；加 `--force` 全部重来）：

```powershell
cd G:\dsh\背单词APP
$env:PYTHONPATH='G:\dsh\.tts-libs'
python gen_audio.py
```

想换音色或语速，改 `gen_audio.py` 顶部的 `VOICE` / `RATE` / `RATE_SLOW`
（可选音色例如 `en-US-JennyNeural`、`en-US-AnaNeural` 更像童声），生成后
**把 `sw.js` 里的 `AUDIO_CACHE` 版本号 +1**，否则手机还用旧音频。

- **加词 / 改故事**：编辑 `index.html` 里的 `PLAN`（词表）和 `STORIES`（故事库），
  两个地方都要加，词要能对上。

## 八、常见问题

**手机打不开 https 地址？**
多半是 Windows 防火墙拦了。用**管理员** PowerShell 跑一次：

```powershell
New-NetFirewallRule -DisplayName "背单词APP" -Direction Inbound -LocalPort 8443 -Protocol TCP -Action Allow
```

**地址栏一直显示"不安全"，有关系吗？**
没有。这是自签证书的正常表现，数据只在你家局域网里，不出网。

**换 WiFi 或电脑重启后手机上的图标打不开了？**
电脑 IP 变了。重跑 `python serve.py`，看新的 https 地址，手机上重新访问并重新添加。

**只想快点用，不想折腾证书？**
用手机**自带浏览器**（小米/华为/QQ 等）打开原来的 HTTP 地址，在菜单里找「添加到主屏幕」。
出来的是快捷方式，能一键进入，但**不是全屏、也不能离线**。

**过程中抓到并修掉的三个真 bug**：
1. **慢速音频没进离线缓存**——`sw.js` 的预缓存清单漏了新增的 `wordsSlow`，
   离线状态下慢速会失效（由 SW 测试发现）。
2. **首页慢速按钮绑定可能中断启动**——原来用 `wrap.querySelector(".slow").onclick`，
   一旦取不到子元素就抛异常、整个首页白屏；改成在容器上做事件委托。
3. **跟读按钮绑定同样会中断启动**——直接调用 `addEventListener`，在极简/老环境下
   会抛异常；已加能力判断，并保留"轻点开始、再点停止"的回退。

**跟读功能的测试覆盖**：不支持录音的降级、http 下提示需要 https、麦克风权限被拒、
空录音兜底、回放与重录、**重录时释放旧录音**（防内存泄漏）、
**离开步骤/关闭面板时释放麦克风**、录音时长上限、单词与句子跟读目标互切 —— 共 **45 项**。

**关于发音质量的说明**：音频由 `edge-tts` 的 `en-US-AriaNeural` 生成，是标准美式发音。

**发音内容做过字节级核验（比"听一遍"更硬）**：`edge-tts` 对固定的
`(文本, 音色, 语速, 音高)` 是**字节确定的**，所以把每个音频的预期文本用同一套参数
重新合成一遍、比对 MD5，就能证明它念的内容和配置都对——不同音色或不同语速
不可能产出同样的字节。

- 全部 **180 个文件**（150 正常速 + 30 慢速）**字节完全吻合**预期文本
- 4 个抽查样本的 MD5 由主流程**独立复核**，全部吻合
- Whisper 语音识别交叉验证：base.en 精确命中 139/150，small.en 把 11 处不一致中的 7 处
  纠回原文，剩下 4 处是同音词/连字符（`Peek-a-boo!`→peekaboo、`cat`→Kate 等），
  **全部属于识别误差，音频本身无缺陷**
- 磁盘 180 个 mp3 与 `manifest.json` 清单**完全一致**（无缺、无多、无重复）

**仍未验证的一点**：**没有真机试听**（当前工具链无法处理音频输入）。
音色好不好听、语速合不合适，仍需你在手机上确认。如需换音色
（例如更接近童声的 `en-US-AnaNeural`），按第六节重生成即可。

**顺带发现的一个坑**：`edge-tts` 在同样的参数下，**`sun` 和 `son` 会生成完全相同的字节**
（真实同音词碰撞）。这不影响现在使用（文件名就是区分依据），但如果以后要用语音识别
来做质检，这类词永远无法靠听辨别，只能靠清单或字节比对。
